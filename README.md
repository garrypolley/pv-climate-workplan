# Prairie Village climate actions

A small site that reads a 45-row action table against the City of Prairie Village [Community Climate Action Guide](https://www.prairievillageks.gov/DocumentCenter/View/602/Community-Climate-Action-Guide-PDF) (November 2025).

The guide’s chapter “Prairie Village’s Role in Climate Action” lists 38 city actions with codes EL, EE, T, and W. The table’s Source column uses those codes. Each code appears on exactly one row. Twenty-two other rows cite the Environmental Committee and are not in the guide.

The table was transcribed from photographs. The sheet shows no title, date, or adoption line. Guide wording comes from the city’s PDF.

The same page carries the four-question feasibility scale and the six-box prioritization matrix. The 45 actions are not scored and are not placed in matrix boxes yet.

Live site: https://climate.garrypolley.com

Open `index.html` in a browser, or serve this folder:

```
python3 -m http.server 8765
```
